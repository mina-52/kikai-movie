# 喜界島まとめ動画 構成案（v2）

素材の詳細は [素材一覧.md](素材一覧.md) を参照。
YouTube「Imanishi's Lab」の公開動画9本（使い方チュートリアルは除く）に加え、Google Drive の未公開素材もすべて使う。

## コンセプト

**「島の歌でめぐる喜界島」**（約3分。最終的な長さは歌の尺に合わせる。16:9、1080p）

- **主役は島の方の歌**（後日支給）。歌声がいちばんよく聞こえるように、すべての音をミックスする。
- 歌のない部分（前奏・間奏・後奏）では、**現地の環境音**（波・風・ガジュマルの森）を前に出し、島の空気を「耳で」感じてもらう。
- 時間の流れは**昼から夕方へ**: 一本道（昼）→ 海 → 石垣 → 森 → 夕日の海岸 → 空からの島、で一日を閉じる。
- BGMは後日支給。歌がある部分では入れないか、ごく小さくする。

## 音のミックス方針

| 要素 | 歌の最中 | 歌のない部分 |
|---|---|---|
| 島の方の歌 | 主役（-14 LUFS 基準） | — |
| 現地の環境音 | 歌の約-18dB下にうっすら | 主役 |
| BGM（後日支給） | 入れないか、ごく小さく | 環境音の下に控えめに |

- 歌は声を聞き取りやすく補正する（低音のカット、こもり除去、軽いコンプレッサー）。
- 歌が鳴っている間は、環境音とBGMが自動で下がるようにする（`sidechaincompress`）。
- 環境音は Sony のカメラ（PCM 音声）と iPhone の音を使う。風のノイズを除いて自然な音にする。
- 無音の素材（Video Project 系、DJI空撮、2226C…）には、同じ場所の環境音を重ねる。
- 歌詞が島の言葉の場合は、**歌詞字幕（方言＋共通語訳）**を入れると引きつけが強くなる。歌詞データがあればもらいたい。

## v2 での変更（支給音源を反映）

- **音声**: 支給音源（4分35秒）を全編に使い、曲を途中で切らないよう、映像を素材の追加で曲の長さに合わせた。
- **現地音**: 波の音のシーン（イントロ・海・間奏・夕日の波打ち際・アウトロ）だけ残し、それ以外はカット。
- **テロップ**: 「阿伝」を削除。
- **スマホ縦動画・縦写真**: ぼかし背景をやめ、16:9 いっぱいに切り出す。動画は手ぶれ補正（vidstab）と、HDR から変換した色をほかの素材に合わせる色補正を入れる。
