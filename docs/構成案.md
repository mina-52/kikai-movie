## コンセプト

**「耳で旅する喜界島」**（約2分30秒、16:9、1080p）
島に入るところから、海 → 石垣 → 畑 → 巨木と巡り、最後に空から島を見下ろして終わる。
映像よりも**音を主役**にする構成にする。各シーンの冒頭で、映像より0.5〜1秒早く環境音を鳴らし（Jカット）、音に引っ張られて画面が切り替わるようにする。

## 音声の処理（共通）

- **音量をそろえる**: ffmpeg の `loudnorm` で全体を -14 LUFS（YouTubeの基準）に合わせる。
- **環境音を強調する**: 低音のカット（約80Hz以下、風のボコボコ音を除く）、軽いノイズ除去（`afftdn`）、2〜5kHzを少し持ち上げて波音を立たせる。
- **BGM**: 後日支給される音源を使う。
- **BGMを自動で下げる**: `sidechaincompress` を使い、環境音が大きいところではBGMを下げる。
- **無音の空撮2本**: 同じエリアの地上クリップの環境音をループさせて重ねる。
- **立体感**: 波の音は左右にゆっくり振る（パン）。イヤホンで聴いたときの没入感を高める。
